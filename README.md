# follient

ブックマークを Pinterest 風のタイルで表示する、Firefox の新しいタブ。

新しいタブを開くとブックマークがカードで並びます。フォルダはフォルダの絵、
ページはそのページの見出し画像。クリックでフォルダの中に入っていけます。

---

## できること

**ブックマークがそのまま壁になる**
新しいタブを開くと、ブックマークのルートが表示されます。フォルダとページが
同じ形のカードで、高さの揃わないタイルとして並びます。

**ページはその見た目で分かる**
各ページの OGP（ページが自分で用意している見出し画像とタイトル）を取ってきて
カードにします。OGP 画像を用意していないページについては、**そのページを実際に
開いて見た目を撮り、その画像を使います**。どちらも無い場合だけ、ホスト名の
頭文字を置いたタイルになります。

**フォルダを掘っていける**
フォルダのカードをクリックすると、その中身が同じ形式で表示されます。
ルート以外にいるときは、左上に「↑ 上層に戻る」が出ます。パンくずの各段も
クリックできます。ブラウザの戻る／進むも使えます。

**下に行くほど読み込む**
画像はカードが画面に入った時点で初めて取りに行きます。ブックマークが何百件
あっても、開いた瞬間に全部を読みに行くことはありません。

**ライト／ダークの両方に合わせる**
OS やブラウザの配色設定に追随します。

## 入れかた

### 署名済みの XPI を受け取った場合

XPI ファイルを Firefox のウィンドウにドラッグ＆ドロップし、表示される確認で
「追加」を選びます。次に新しいタブを開くと follient になります。

初回は「新しいタブ設定が変更されました」という確認が出るので、
**「変更を維持」** を選んでください。選ばないと元の新しいタブのままになります。

### 未署名の XPI を受け取った場合

通常版の Firefox には恒久インストールできません（署名が必須のため）。
一時的に読み込んで試せます。

1. アドレスバーに `about:debugging#/runtime/this-firefox` と入力
2. 「一時的なアドオンを読み込む」を押し、XPI ファイルを選ぶ
3. 新しいタブを開く

この方法で入れたものは **Firefox を終了すると消えます**。試用向けです。

### 更新時に権限の確認が出ることがあります

隠しタブを使うために「タブを隠す」権限が必要です。以前の版から更新すると
Firefox が確認を出し、承認するまで拡張機能が止まります。承認してください。

Firefox 自体が「拡張機能がタブを隠しています」という案内を一度だけ出すことも
あります。follient の撮影用タブのことです。

## 使ううえで知っておくとよいこと

### 撮影は画面に出ずに行われます

OGP 画像を持たないページの見た目を撮るとき、そのページを実際に開く必要が
あります。この読み込みは**隠しタブ**の中で行います。ウィンドウは作らず、
タブ一覧にも現れないので、**画面には何も出ず、入力中のフォーカスも奪いません**。

サムネイルはページ全体ではなく、**左上の見出し付近を拡大して切り出したもの**です。
大きなウィンドウで使っていてもカード上で内容が読めるようにするためです。
撮影のあいだだけそのサイトの表示倍率を一時的に変えますが、撮影が終わると
**元の値に戻します**。あなたがそのサイトに設定していた拡大率はそのまま保たれます。

撮影は 1 件ずつ、間隔を空けて行います。同じサイトへ続けてアクセスしないよう、
同一サイトに対しては 90 秒以上空けます。ブックマークが同じサイトに大量に
ある場合、埋まっていくまで時間がかかりますが、これは相手のサイトに負担を
かけないための意図的な動作です。

一度撮った画像は保存され、30 日間は撮り直しません。

### プライバシー

- ページの取得も撮影も、**すべてあなたの Firefox の中だけ**で行われます。
  外部のサービスには一切送りません。
- 撮影はあなたのログイン状態のまま行われます。ログインが必要なページを
  ブックマークしている場合、**ログイン後の画面が写った画像が手元に保存されます**。
  他人と画面を共有する場合はご注意ください。
- 取得した情報（OGP・スクリーンショット）はブラウザ内にのみ保存されます。

### 保存した画像を消したい

Firefox の「設定 → プライバシーとセキュリティ → Cookie とサイトデータ」から
拡張機能のデータを削除するか、拡張機能を一度削除して入れ直してください。

## うまく動かないとき

**新しいタブが follient にならない**
「変更を維持」を選び損ねている可能性があります。`about:addons` から follient を
一度無効にして、もう一度有効にすると確認が再表示されます。

**カードが頭文字のタイルのまま**
そのページが OGP 画像を持っておらず、撮影の順番待ちの可能性があります。
間隔を空けて撮るため、同じサイトが多いフォルダでは時間がかかります。
しばらく経っても変わらない場合、そのページは撮影に失敗しています
（読み込みに時間がかかりすぎる、真っ白なページ、など）。

**フォルダが空だと言われる**
そのフォルダに、表示できるブックマーク（http/https/ftp/file）が無い状態です。
