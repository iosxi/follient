# follient

ブックマークを Pinterest 風のタイルで表示する、Firefox の新しいタブ。

新しいタブを開くとブックマークがカードで並びます。フォルダはフォルダの絵、
ページはそのページの見出し画像。クリックでフォルダの中に入っていけます。

---

## できること

**ブックマークがそのまま壁になる**
新しいタブを開くと、ブックマークのルートが表示されます。フォルダとページが
同じ形のカードで、高さの揃わないタイルとして並びます。

**ページはその見た目で分かる**
各ページの OGP（ページが自分で用意している見出し画像とタイトル）を取ってきて
カードにします。OGP が無いページでも、そのページの構造化データや **RSS / Atom
フィード**、本文中の大きな画像から見つけられれば、それを使います。

そこまでで見つからなかったページだけ、**実際に開いて見た目を撮り**、その画像を
使います。どれも無い場合にホスト名の頭文字を置いたタイルになります。

**フォルダを掘っていける**
フォルダのカードをクリックすると、その中身が同じ形式で表示されます。
ルート以外にいるときは、左上に「↑ 上層に戻る」が出ます。パンくずの各段も
クリックできます。ブラウザの戻る／進むも使えます。

**下に行くほど読み込む**
画像はカードが画面に入った時点で初めて取りに行きます。ブックマークが何百件
あっても、開いた瞬間に全部を読みに行くことはありません。

**開けなくなったページが分かる**
ページが 404（もうありません）や 403（見られません）などを返した場合は、
画像の代わりに**その番号と意味を書いた小さなタイル**になります。接続そのものが
できないドメインも分かります。整理の目印に使えます。

**取得方法を選べる**
`about:addons` の follient の「設定」から、サムネイルの取得方法 1〜5 を
それぞれ入り切りできます。変更はすぐ反映されます。どれでも画像が
見つからなかったページは「サムネイルなし」と表示されます。

**フォルダ内での順番が分かる**
ブックマークのカードには、サムネイルの左上にそのフォルダで何番目かを
数字で貼ります。フォルダは数に入れず、ブックマークだけを 1 から数えます。

**カードごとの操作**
ブックマークのカードのタイトル行の右端にある ︙ から「サムネイル更新」を
選べます。保存された結果を無視してその場で取り直すので、サイト側が後から
画像を付けた場合や、うまく取れなかった場合に使えます。フォルダのカードには
選べる操作が無いので、︙ は出ません。

**rawkuma の作品は、どこまで読んだかが分かります**
rawkuma.net の作品ページをブックマークしていると、カードに全部の話数を新しい
順に並べます。場所は 3 行ぶんしか取らないので、古い話はその中を下へ送って
辿ります。すでに開いたことのある話は青地になるので、続きがどこか一目で
分かります。
この 1 サイト専用の機能なので、設定画面で切れます。

**一度出たサムネイルは消えません**
読めた画像は縮小して手元に保存し、次からはそれを表示します。相手のサイトが
不安定でも、一度表示できたサムネイルが次に開いたときに消えることはありません。
**期限はありません。** 消えるのは、カードの ︙ から「サムネイル更新」を選んだ
ときか、設定画面で一括して消したときだけです。設定画面に保存件数と概算の
容量が出ます。

同じ画面に「取得済みの画像を消す」ボタンがあります。取得方法を変えた直後など、
すぐ反映したいときに使ってください。次にカードが表示されたときに取り直します。

**読めなかったときのやり直しを調整できる**
画像の場所は分かったのに読めないことがあります。相手のサイトが一時的に断ったり、
短い時間に多くの要求が来たことで絞ったりするためです。設定画面で「やり直す回数」
と「やり直す間隔を伸ばしていく」を変えられます。既定は 6 回・間隔を伸ばす、です。
ブックマークが同じサイトに大量にある場合、間隔を伸ばしたほうがよく取れます。

**ライト／ダークの両方に合わせる**
OS やブラウザの配色設定に追随します。

## 入れかた

### 署名済みの XPI を受け取った場合

XPI ファイルを Firefox のウィンドウにドラッグ＆ドロップし、表示される確認で
「追加」を選びます。次に新しいタブを開くと follient になります。

初回は「新しいタブ設定が変更されました」という確認が出るので、
**「変更を維持」** を選んでください。選ばないと元の新しいタブのままになります。

### 未署名の XPI を受け取った場合

通常版の Firefox には恒久インストールできません（署名が必須のため）。
一時的に読み込んで試せます。

1. アドレスバーに `about:debugging#/runtime/this-firefox` と入力
2. 「一時的なアドオンを読み込む」を押し、XPI ファイルを選ぶ
3. 新しいタブを開く

この方法で入れたものは **Firefox を終了すると消えます**。試用向けです。

## 使ううえで知っておくとよいこと

### プライバシー

- ページの取得は**すべてあなたの Firefox の中だけ**で行われます。
  外部のサービスには一切送りません。
- 取得のときに、あなたのログイン情報 (Cookie) は送りません。ログインが
  必要なページからは、ログインせずに見える範囲しか取れません。
- 取得した情報はブラウザ内にのみ保存されます。

### 保存した画像を消したい

Firefox の「設定 → プライバシーとセキュリティ → Cookie とサイトデータ」から
拡張機能のデータを削除するか、拡張機能を一度削除して入れ直してください。

## うまく動かないとき

**新しいタブが follient にならない**
「変更を維持」を選び損ねている可能性があります。`about:addons` から follient を
一度無効にして、もう一度有効にすると確認が再表示されます。

**カードに「サムネイルなし」と出る**
そのページから follient が取り出せる画像が無かった、ということです。OGP も
構造化データもフィードも持たないページや、ログインしないと中身が見えない
ページで起きます。ページ側が用意していない以上、follient にできることは
ありません。

カードの ︙ から「サムネイル更新」を選ぶと、保存された結果を無視して
取り直します。サイト側が後から画像を付けた場合はこれで出ます。

**フォルダが空だと言われる**
そのフォルダに、表示できるブックマーク（http/https/ftp/file）が無い状態です。
